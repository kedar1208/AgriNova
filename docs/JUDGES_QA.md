# Judges' Q&A preparation
**Why are the two solutions genuinely different?** AgroCast is short-horizon *prediction* of hazard exposure for an existing crop (weather features → thresholds → scores; soil-water bucket). FarmOptimizer is season-long *decision optimisation* (Monte-Carlo scenarios → yield model → CVaR linear programme). Different inputs, algorithms, outputs, modules; they don't import each other and share only crop parameters.
**Why these algorithms?** Little labelled crop-loss data exists for small farms, so a trained ML model would be unjustifiable; explainable agronomic models (FAO-56, FAO-33) can be audited by judges and farmers. LP/CVaR gives an exact, convex, explainable optimum, not a heuristic search.
**What is innovative?** Point-level explanations for every score; measured-vs-estimated labelling; risk-aware (CVaR) crop planning with live what-ifs; offline-first with provenance labels; one-click PDF.
**How reliable are predictions?** We make no accuracy claim. Scores are heuristic exposure indicators; forecast quality comes from Open-Meteo; thresholds are literature-style defaults needing local calibration. Tests verify logic (monotonicity, constraints), not real-world accuracy.
**Missing weather data?** Validation → implausible values removed → interpolation (≤2 days) → median → Hargreaves ET0; rows flagged imputed; unusable input raises a clear error; offline falls back to labelled synthetic data; missing humidity → rain proxy (stated).
**Weather changes suddenly?** Forecast is re-fetched (30-min cache) and all scores/alerts recompute; the bucket restarts from measured moisture if provided; FarmOptimizer's rainfall-shift slider shows plan sensitivity.
**How does it help small farmers?** Plain-language alerts, irrigation timing/volume (saves water/energy), plans that respect a small budget (e.g., ₹20,000) and water limits, offline mode, PDF to share with KVK/officers. Honest gap: regional-language/SMS delivery is future work.
**Limitations?** See report §12 — unvalidated heuristics, illustrative crop economics, no price volatility, no pest or sowing-date model, user-entered rainfall normals.
**Real-world deployment?** Pilot with a KVK/FPO: calibrate thresholds with ICAR/IMD district data, add Hindi/Marathi etc. via WhatsApp/SMS bots, host on a low-cost cloud, cache forecasts, collect farmer feedback, validate against observed losses before wider claims.
